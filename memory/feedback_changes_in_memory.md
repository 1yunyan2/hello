# 代码修改记录必须写入 memory/

**规则**：对代码的任何修改（bug修复、功能新增、参数调整、架构变更），必须同步更新到 `memory/` 目录下的可见文件，用户可以直接打开查看。

**Why**：用户无法通过翻看对话历史快速回顾修改记录；memory 目录是项目级的持久知识库，代码变更只记录在对话上下文里等于没记录。

**How to apply**：
- **Bug 修复** → 更新 `bugs/ALL_BUGS.md`（每日时间线）+ 对应 `BUG-XXX.md` 状态
- **每日改动** → 更新或新建 `daily/YYYY-MM-DD.md`，列出所有改动文件和内容
- **架构/参数决策** → 新建或更新 `decisions/DEC-XXX.md`
- **不要等到用户说"总结"才写**，改完代码立刻同步到对应记忆文件

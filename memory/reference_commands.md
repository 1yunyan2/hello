# 大类指令清单（共 10 大类，30 个子能力）

> 使用方式：直接说大类名称，自动执行该类下全部子能力。也可单独说子能力名称精确触发。

---

## 1. 编译调试

| 子能力 | 触发词 | 说明 |
|--------|-------|------|
| 一键编译诊断 | "编译" / "build" | 运行 idf.py build，分析报错，自动修复 |
| 崩溃日志分析 | "崩溃分析" / 贴 backtrace | 解析 Guru Meditation Error，定位崩溃函数和行号 |
| 串口日志分析 | "分析日志" / 贴 monitor 输出 | 分析启动流程、初始化顺序、异常警告 |

---

## 2. 代码质量

| 子能力 | 触发词 | 说明 |
|--------|-------|------|
| 代码审查 | "审查 xxx.c" / "review" | 内存安全、并发安全、ESP-IDF 最佳实践、风格检查 |
| 模块健康报告 | "检查项目状态" / "健康报告" | 扫描 TODO/FIXME、未提交修改、踩坑交叉比对 |
| 内存使用分析 | "分析内存" | 任务栈水位、heap 碎片、SPIRAM 分配比例 |

---

## 3. 文档生成

| 子能力 | 触发词 | 说明 |
|--------|-------|------|
| API 文档 | "生成 API 文档" | 提取函数签名、参数、使用示例 |
| 接线文档 | "生成接线文档" | 从 bsp_config.h 生成引脚映射表 |
| README 更新 | "更新 README" | 根据代码状态生成项目说明 |

---

## 4. 项目管理

| 子能力 | 触发词 | 说明 |
|--------|-------|------|
| Git 操作 | "提交" / "创建PR" / "看看改了什么" | 生成 commit message、PR 描述、变更可视化 |
| 依赖管理 | "检查依赖" | 分析 idf_component.yml 版本兼容性 |
| 分区表分析 | "分析分区表" | Flash 布局可视化、溢出检测 |

---

## 5. 记忆管理

| 子能力 | 触发词 | 说明 |
|--------|-------|------|
| 每日总结 | "生成今日总结" | 对话要点、修改记录、错误、明日待办 |
| 周报总结 | "生成周报" | 汇总本周所有每日总结，提炼进展和计划 |
| 踩坑记录 | 自动 + "扫描坑点" | 编译错误、运行崩溃、配置问题自动记录 |
| 决策记录 | 自动 + "记录决策" | 架构决策的背景、对比、理由 |

---

## 6. 硬件辅助

| 子能力 | 触发词 | 说明 |
|--------|-------|------|
| 引脚分析 | "分析引脚" / "引脚分配" | 已用/空闲/不可用统计，冲突检测 |
| 引脚推荐 | "推荐引脚" / 描述新外设需求 | 根据外设需求推荐最优引脚方案 |
| 原理图审查 | "检查接线" / 描述硬件连接 | 验证接线合理性，检测冲突和风险 |

## 7. 开发辅助

| 子能力 | 触发词 | 说明 |
|--------|-------|------|
| 架构补全 | "我要加 xxx 功能" | 分析架构 → 生成方案 → 创建文件 → 写代码 → 编译验证 |
| 批量重构 | "把所有 xxx 改成 yyy" | 安全全局替换，先预览再执行 |
| 结构整理 | "整理项目目录" | 分析目录结构，建议优化方案 |

## 10. 自动化（被动触发，无需指令）

| 子能力 | 触发条件 | 说明 |
|--------|---------|------|
| 改码自动编译 | 修改 .c/.h 文件后 | 自动 build 检查，有错立即修 |
| 开文件自动扫描 | IDE 打开新文件 | 读取文件，扫描问题，结合踩坑日志提醒 |
| 关键模块守卫 | 修改关键文件前 | 自动提醒该文件的历史坑点 |

峰值内部 SRAM 22KB → 75KB+（+53KB）
迁移清单：audio_feed(8KB) + afe_fetch(4KB) + reminder(8KB) + interaction_worker(4KB) + heartbeat(4KB) + async_ww_update(4KB) + servo_worker(4KB) + ws_reconn(6KB) = 42KB 任务栈，+ 10KB 静态 buffer（s_aec_ref/s_aec_interleaved/input_buffer）+ 1KB 采集 buffer。

安全论证：ESP32-S3 PSRAM 通过 MMU cache 访问，task stack 放 PSRAM 对非 ISR 任务完全兼容。I2S DMA 内部维护自己的 DMA ring buffer，用户 buffer 只是 CPU memcpy 目标，放 PSRAM 安全。NVS 写入会短暂挂起 CPU1（毫秒级音频帧丢失），不影响正确性。

已保留 WiFi task 在内部 SRAM（原 SPIRAM 版被注释，疑有特殊需求）。

+30-17

// 收到服务端 "started" 后

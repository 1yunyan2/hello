2026-09-21 重做 `interaction.c` 的 4_x 好奇三组（`EMO_CURIOUS1~3`）。做之前逐帧拆了三张素材，结论推翻了原设计前提。

**⭐ 推翻的旧前提：好奇 = 歪头**
源文档标题《21 好奇歪头》是错的。三张素材（`好奇.gif` 6.0s/144帧、`好奇2.gif` 5.0s、`好奇 2.gif` 5.0s）的脸**朝向恒定**，零倾斜零转向——好奇全靠"眼睛大小 + 眉毛 + 冒问号"表达。
而机芯头部**只有偏航一轴**（10~170°，中位 90°），横滚物理上不存在。
旧代码把"歪头"翻译成 70↔120 的左右扫视（50° 来回）⇒ 在只有偏航轴的机芯上**读作"摇头=否定"**，语义正好反过来。这就是用户说"别扭"的根。
**新原则**：身体只做「定向 → 停留 → 回神」；**绝不连续来回摆动**（=摇头）；**停顿是把"打量"和"摇头"区分开的唯一手段**。

**⭐ 三条硬件事实（这次才查清，之前所有情绪表都踩了）**
1. **手臂基线是 15°，不是 90°** — `ARM_CENTER_DEG`(bsp_config.h:332)=15.0f。手臂静止/归位在 15°，**角度越大越向前抬**（170=向前极限，"防止撞头"）。旧表把手臂摆在 30~45 附近当中位用是错的。
   ⚠️ `servo_manager.c:115` 注释写"手臂回 ARM_CENTER_DEG(33°)"——**33 是旧的，实际 15**（bsp_servo.c:933 的"臂15°"才对）。
2. **要"保持一个姿势不动"，必须用带 `hold_ms` 的 seq 步，不能用 `seq_len=0`**
   `servo_manager.c` 在目标点之后**总会**追加归中点，`seq_len=0` 的轴会被立刻拉回。正确写法：`{角度, 0, 大hold}`。
3. **三轴各自归中**（servo_manager.c:238-239）：某轴走完自己的点就立即回中位，不等别的轴。

**⚠️ 头角方向文档打架**：[bsp_servo.c:76-77](d:/new/Echopals/Echo2/main/bsp/bsp_servo.c#L76) 写 `HEAD_MIN_ANGLE 10` = 向左极限，而 [interaction.c:12](d:/new/Echopals/Echo2/main/ui/interaction.c#L12) 写"左+ 右−"(左转30°→120)。**二者相反**。全表都按 interaction.c 的约定填，bsp 那句注释过时。上板需用一次 90→130 单步确认。

**三组各自的性格（核心是"各不相同"）**
- `4_1` 长停打量：头偏左 24°，四拍长停(700~1300ms)，逐拍卡素材的 3 个 "?"(1.1/3.1/5.0s)；左臂抬到半空**停住**("等一下，你说什么"手势)，右臂只小抬后同姿势钉住 ⇒ 一前一后不对称
- `4_2` 侧耳慢呼吸：头**定向一次后彻底冻结**（一个 `{110,0,4600}` 长 hold），节奏全给两臂——t≈2.3s 两臂**反相**一抬一落，对上素材眯眼呼吸节拍
- `4_3` 凑近端详：头**只朝右、绝不回头**(30°→12°→8° 递减)，两臂**完全同步**前倾（素材是"眨眼"，两侧同时故同步才对）

**⚠️ 未上板验证**。三组动作总时长 5.2/5.1/4.9s，对齐素材 6.0/5.0/5.0s。

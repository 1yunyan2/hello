---
name: Token预算意识
description: 每次回答前先快速判断token是否够完成目标，避免半途而废浪费token
type: feedback
---

回答问题前，先用极少token快速评估：当前剩余上下文是否足够完成整个任务。

**Why:** 如果token不够完成目标，前面的思考和输出全部浪费。用户经历过任务做到一半被截断的情况。

**How to apply:**
- 收到问题后，先极简评估任务复杂度和所需token量
- 如果判断token不够，立即告知用户，建议拆分任务或开新对话
- 如果够用，正常执行
- 大任务优先分步完成，每步产出可用结果，避免"全做完才有用"的情况
- 每次花费较多token时记录下来，帮助后续判断

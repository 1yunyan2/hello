---
name: 总结自动流程
description: 用户说"总结"时自动执行：记忆写入+git提交+坑点&改动记录，无需询问
type: feedback
---

用户说"总结"时，自动完成以下全部步骤，不需要询问确认：

1. **生成当日总结**（已提交 + 未提交改动 + 核心进展 + 待办）
2. **写入每日记忆** `memory/daily/YYYY-MM-DD.md`
3. **记录当日坑点** 到 `memory/bugs/` 目录（如有新坑）
4. **git commit 提交**所有未提交的改动
5. **更新 MEMORY.md 索引**
6. **总结内容固定显示在对话中**（即总结文本直接输出给用户看，不能只写入记忆不显示）

**Why:** 用户希望"总结"是一个一键操作，省去反复确认的时间，且总结内容必须在对话中可见。
**How to apply:** 每次用户说"总结"，先在对话中输出完整总结内容，再执行记忆写入、提交等操作。总结内容不能省略或隐藏。

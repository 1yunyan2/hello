2026-09-21 重做 `interaction.c` 的 7_x 怕痒四组（`EMO_TICKLISH1~4` = 39/40/41/42，行落在 interaction.c:1488 起，块头注释 1443）。方法同 [[curious_4x_redesign]] / [[grieved_5x_redesign]] / [[shy_6x_redesign]]。

**素材实测（四张全是"高频等周期抖动"，但频率与幅度差得很开）**

| 素材 | 时长 | 基础周期 | 重复次数 | 幅度 | 内容 |
|---|---|---|---|---|---|
| `怕痒.gif` → 7_1 | 5.00s | 420ms | ~11.9 | 小 | 眉/眼合上又分开，脸不动 |
| `怕痒2.gif` → 7_2 | 5.00s | 500ms | ~9.9 | 中 | 透明底+^^眉 ↔ 灰牌+低眉 |
| `怕痒 2.gif` → 7_3 | 5.33s | 290ms | ~18.1 | 最小 | 高弧眼+波浪嘴 ↔ 平眼平嘴 |
| `怕痒到扭动.gif` → 7_4 | 5.33s | 670ms | ~7.9 | 最大 | ★唯一"脸真的在动" |

7_4 的四相位实测：左右眼高差 `-5.0 / -0.4 / +4.7 / -0.5 px`，双眼间距 `97.5 / 97.2 / 92.2 / 97.2 px` ⇒ 整脸既左右倾（roll）又时而横向压扁（≈偏航）。
⇒ **7_1/7_2/7_3 三张画面几何零位移**（动的只有眉、眼、嘴），舵机复现不出来，**这三条动作只能自己发明**；只有 7_4 有真实位移可照做。

**旧版问题**：四张**逐字复用同一条**（注释自写"复用 7_1"），手臂值 60/40/30 落在基线 15° 附近 ⇒ 实际只动 45/25/15°。同 [[grieved_5x_redesign]] 那类"幅度没减基线"的毛病。

**⭐设计（四张主语/节奏/快慢结构全不同，互不复用）**
- **7_1** 主语=两臂，**头全程钉死**。同相"锯齿"：慢抬 29°@FAST(290ms) + 极快弹回@VERY_FAST(145ms) = 435ms/拍 × 11。头不动是刻意的——"肩膀一抽一抽、脸僵着忍"。
- **7_2** 主语=**两层节奏**。两臂 500ms 对称快摆（15↔38），头**慢一倍** 1000ms 才偏一次（90↔110，偏置不跨中位）。对应素材"眉与灰牌交替"的忙乱。
- **7_3** 主语=两臂**反相**。25°@FAST(250ms)+停 40 = 290ms/半拍（正对素材 290ms）；**右臂整条滞后一拍 290ms** 制造反相。最快最碎。头的相位延迟靠 `.target` 填当前角（零位移，只花 1 帧）+ 首步 `{15, 0, 290}` 实现。
- **7_4** 主语=**全身扭**。头绕中位对称摆 90±16°（74↔106）@FAST 连续不停，32°全幅×10ms = 320ms/半拍 ⇒ 640ms/周期；两臂 15↔50（35°全幅，四张最大）与头**反相**拧动。**靠"头摆+两臂拧"读成扭身而非摇头**，且全程无停顿=不庄重。

**🔴🔴 本次最重要的教训（我自己算错过一倍）**
> **算舵机节拍时，半拍行程 = 【全幅】，不是"半幅"。**
> 7_4 头初版写 `68↔112`（以为 ±22°，其实是 **44° 全幅**）配 `MID`(15ms/度) ⇒ 每半拍 660ms、周期 1320ms，**是素材 670ms 的两倍**。改成 `74↔106`（32° 全幅）配 `FAST`(10ms/度) 才对上。
> ⇒ 凡"A↔B 往复"的设计，**半拍耗时 = |A−B| × ms/度**，别拿 (A−B)/2 去乘。

**★校验手法（这次新加的，建议后面 8_x~14_x 都做）**：写完不编译，用 Python 按 `servo_exec_seq` 的语义**重放一遍时间线**——
① 逐轴把 `.target`（仅 `speed>0` 才追加）与 `seq[]` 拼成点序列；
② 每步耗时 = `|a−cur| × speed_ms`（`speed==0` 时按 `step.speed → seq_speed → axis.speed` 解析），零位移按 1 帧≈20ms；
③ 累加得每轴总时长，与素材时长比对；
④ 顺带卡容量：`点数+1(归中) ≤ BSP_SERVO_SEQ_MAX_POINTS(34)`、`seq_len ≤ ACTION_SEQ_MAX_STEPS(32)`。
本次就是靠它抓出 7_4 头 10890ms（预期 5610ms）这个错。

**实测结果**：7_1 三轴齐 5075ms / 7_2 5230ms / 7_3 5530ms / 7_4 头 5280ms、臂 5950ms。
最大点数 24（7_1 两臂）、最大 seq_len 22，均在容量内。代码区花括号 272/272 平衡。

---
name: 分类指令自动执行所有子能力
description: 用户说一个大类名称时（如"文档生成"），自动执行该类下的所有子能力，不需逐个确认
type: feedback
---

用户要求：当说出一个能力大类名称时，自动执行该类下的所有子能力。

示例：
- "文档生成" → 同时执行 API 文档 + 接线文档 + README 生成
- "调试辅助" → 同时执行 崩溃分析 + 串口日志 + 内存分析
- "项目管理" → 同时执行 Git 助手 + 依赖管理 + 分区表分析

**Why:** 用户不想逐个触发，希望一句话搞定整个类别。
**How to apply:** 检测到大类名称时，自动并行执行所有子能力，最后合并输出。

2026-09-21 重做 `interaction.c` 的 5_x 委屈两组（`EMO_GRIEVED1/2`）。方法同 [[curious_4x_redesign]]：逐帧拆素材 → 定节拍 → 反推身体，不抄源文档。

**素材实测（逐帧 + 差异图，这招最有效）**
- `委屈.gif` → 5_1：5.5s/132帧 = **含泪 + 眼神躲闪**。眼角有静态泪光符号；眼睛（含瞳孔）全程小幅无规律游移（不敢直视），前 ~4.5s 很小，**t≈4.55~5.05s 有一次明显加大的晃动**，然后归位。**无抽泣**、脸朝向不变。
- `委屈2.gif` → 5_2：6.0s/144帧 = **抽泣 + 掉泪**。⚠️**动画周期实为 3.0s（内容重复两遍）**，一周期内约 3 次泪珠滚落（t≈0.79/1.88/2.54s）；眼和嘴持续抽动。
- ⇒ 两张素材**语义完全不同**，旧版共用一套是错的。（源文档叫《15 难过低落》《16 委屈抽泣》——这次"委屈抽泣"这条倒是对上了。）

**🔴 旧版两处硬 bug（系统性错误，其他组大概率也有）**
1. 5_1 两臂都填 `18°`，但**手臂基线是 15°**(ARM_CENTER_DEG) ⇒ 实际只位移 **3°**，远低于死区+齿隙，**上板完全看不见**（[BUG-033] 同款）。
2. 5_2 的"抽泣"写成 `105↔98` = **7°** ⇒ 同样看不见，旧版根本抽不起来。
**教训**：填手臂角度前必须减掉基线 15° 再判断幅度是否 ≥15~20°。**凡见手臂值落在 15~35 区间，几乎必然是"没算基线"的 bug。**

**★判别技巧（本次新学的，省时间）**：把每帧与首帧做**像素差、把差异涂红**渲染出来，一眼就能看出"到底哪儿在动"——比逐帧肉眼看快得多。静止的脸会退成灰色底，动的部分（眼睛/嘴/泪珠）跳红。
**★另一个技巧**：对帧序列算 diff 峰值 + 特定颜色像素计数（如"灰点=泪珠"），能精确拿到**动作节拍时刻**和**动画真实周期**（5_2 的 3.0s 周期就是这么发现的）。

**设计（沿用 4_x 的"定向→停留→回神、绝不连续来回摆"）**
- `5_1` 主语=头：偏右 22° **躲住不动 4.2s**（不敢直视）；三轴的第二拍**刻意都压在 t≈4.53s**（= 素材那次大晃动）⇒ **全身一起瑟缩一下**再停。两臂慢抬到身前**错开高度**停住(88° vs 66°) = "无措地绞手"。总 ~5.8s。
- `5_2` 主语=两臂：抬到脸前(**140°/138°**，向前极限 170 内安全)后做 **4 拍抽泣**，每拍 0.8s = 抽 20°(FAST 200ms) + 停 150 + 回 200 + 停 250。两臂**稳定错开 0.54s**（右臂首拍前多停 800-250=550ms，之后节奏相同）。头先钉在中位 3.8s，收尾时才**偏左**别开 14°（与 5_1 的偏右相反）。总 ~6.0s。
- ⚠️ 这是**全库唯一故意用重复动作**的一组：素材"抽泣"语义本身就是重复，靠"快抽 + 明显停顿"与"匀速挥手"区分。

**⚠️ 未上板**。遗留：① 两组都还用 `vib_light1`，5_2 抽泣其实适合**断续震动** ② 5_2 时间线是按 20ms 帧分辨率手算的，两臂 0.54s 错位是否够明显待实测。

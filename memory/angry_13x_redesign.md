## 三、★死区红线：为什么不敢照抄素材的 333ms

素材 13_1 是 333ms/拍的高频搏动，但**脸部搏动不需要舵机出力**，舵机不能这么干：

- 周期越短 ⇒ 每拍 `hold` 越小 ⇒ 越接近"纯位移机械链"（毁掉情绪，见原则）；
- 更致命：**小幅高频往复正是掉进死区**的成因 —— 每帧位移 < 死区 0.8° 时舵机收不到有效指令
  却持续通电 ⇒ **啸叫 + 干磨塑料齿轮**。旧版 13_2 注释里"幅度必须保持 ±4°否则 MG90S
  啸叫并迅速磨损塑料齿轮"说的就是这件事（虽然它给的 ±4° 这个**数值**本身就是错的，
  它把"危险区"当成了"要求值"）。
- **对策**：本组一律取素材节拍的**整倍数**，并保持 24°/22° 的**大幅** + ≥223ms 的**显式 hold**。
  详见 [[project_servo_motion_curve]]（每帧位移必须 ≥ 死区）。

## 四、设计（两条气质必须相反，且都不许读成"摇头"）

判据来自 [[shy_6x_redesign]]：**围绕中位对称的往复 = 摇头/否定（禁）；
整体偏置在中位一侧的往复 = 赌气（可做）**。两条的头**全程都不跨 90°**。

### 13_1「生气①」—— 爆发式怒气（主语 = **两臂**）
- 两臂 15→72°（抬 57°，VERY_FAST）绷住，然后 **15 次位移**：
  `{72 ↔ 48，24° 全幅 @VERY_FAST 单程 120ms + 停 223ms}` = **686ms/拍**
  （= 素材 333ms 的 2.06 倍）。
  **左右臂逐字相同 = 同相**，一起抖 = "身子在颤"。
  末尾停在 **48（低处）** 再归中 —— 8 落 7 起，刻意不对称，读起来是"被压住"不是"弹回来"。
- 头 **偏左 24°（114°）** 别过去，只做 3 次**慢**调：
  `{114,0,2400} {106,MID,900} {114,MID,900} {108,MID,820}`，
  间隔 2400/1020/980ms = 两臂 686ms 的 **1.4~3.5 倍**，档位 MID（臂是 VERY_FAST）
  ⇒ 满足 8_x 原则②③（头慢一档软一档、不同速不同幅）。
  幅度也不同：头 8°/6°，臂 24°。
- 实测总时长：**头 6000 / 左臂 5988 / 右臂 5988ms** ⇒ max **6.00s = 素材 6000ms 的正好 1 倍周期**。

### 13_2「生气②」—— 全身一起使劲（主语 = **头也抖**，两臂反相砸）

> 🔴 **初版被用户否决**。初版是"头偏右 22° **僵住 2 秒** + 只做 8°/6° 微调、两臂反相 1000ms/拍"，
> 用户上板前看代码指出 **"第二个愤怒的节奏很慢，体现不出愤怒吧"** —— 说得对。
> **根因不是"臂的 1000ms"，而是头在 5.5s 里有 3.5s 零运动**：
> `{68,0,2000}` 一个静止段就 2.1s，之后只挪 8°、再挪 6°，
> 头总运动量 36° 而时长的 64% 是静止。
> **一次踩了自己两条规矩**：①违反 8_x 原则①（头不许整条钉死几秒，2.1s 静止读起来是"坏掉"）
> ②违反本组刚立的"死区红线"（8° 用 MID 走 = 每帧约 1.3°，只比死区 0.8° 高一点，余量极薄）。
> **还有一处是我"加戏"**：把"素材 500ms > 素材 333ms"读成"闷 = 慢"。
> 但 500ms = **2Hz，客观一点不慢**；素材只有"规律压眉"这一个事实，**推不出"闷"**。

**修正后**（头从"主语却不动"改成"主语真的在动"，且比 13_1 更快）：
- 头 **偏右 30°（60°）** 别住后**自己也抖**：
  `{60 ↔ 76，16° 全幅 @FAST 单程 160ms + 停 120ms = **560ms/拍**}`
  —— **560 < 686（13_1），是全组最快的一条**，直接回应"节奏很慢"。
  范围 60~76 **离中位 14~30°**（比初版的 68~76 离得更远）⇒ 明确的偏置往复，不是摇头。
- 两臂**低位砸**：`{15 ↔ 40，25° 全幅 @VERY_FAST 单程 120ms + 停 160ms = **560ms/拍**}`
  = **与头同拍**，但不同速（VERY_FAST vs FAST）不同幅（25° vs 16°）⇒ 满足 8_x 原则③。
  **15° 就是手臂基线**，所以这是"在身前一下一下地砸/拍"，与 13_1 的 48~72 高位挥形成对比。
- 两臂**反相**：右臂整条晚 **280ms（= 半拍 560/2）**，首步 hold 160→440 ⇒ 左臂落时右臂抬。
- 实测总时长：**头 4980 / 左臂 4520 / 右臂 4800ms** ⇒ max **4980ms ≈ 素材 5000ms（500ms×10 拍）**。

### 两条的区分点（五条）
| | 13_1 | 13_2 |
|---|---|---|
| 节奏 | 686ms/拍 | **560ms/拍（更快）** |
| 主语 | 两臂 | **头（真在抖）** |
| 两臂相位 | **同相** | **反相**（右臂整滞后半拍 280ms） |
| 臂位 | **48~72 高位挥** | **15~40 低位砸** |
| 头 | **偏左 24°**，只做 3 次慢调 | **偏右 30°**，同拍快抖 |

> ⭐ **本次的通用教训（后面 14_x 起照用）**：判断一条情绪"像不像"，
> **先看每个轴在整段里有没有长于约 1s 的零运动段**，而不是先看节拍快慢。
> 初版 13_2 的节拍（臂 1000ms）其实不算离谱，"不像愤怒"是**头的 3.5s 静止**造成的。
> ⇒ 但"节奏"被用户点名也不是白说的：修好静止问题后仍要把拍子压下来（686→560），
> **静止和节奏是两个独立的毛病，得分别治**。

## 五、校验手法（写完**不编译**）

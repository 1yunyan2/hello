# BUG-004 WebSocket 握手消息类型字段错误

**状态**：已修复
**发现日期**：2026-04-08
**修复提交**：`e96b8bc` feat(audio): 集成AFE音频前端处理并优化PCM数据流
**文件**：`main/protocol/websocket_client.c`

## 现象
WebSocket 连接建立后，服务端不响应握手，会话无法进入 LISTENING 状态，
音频数据被丢弃，对话流程卡死。

## 原因
客户端握手消息中 `type` 字段值写成 `"start"`，
但虾哥服务端期望的握手响应类型是 `"started"`。

## 修复
**文件**：`main/protocol/websocket_client.c`
将握手 JSON 中 `"type":"start"` 改为 `"type":"started"`。

## 教训
协议字段值需严格对照服务端文档，不能凭主观命名猜测。
建议在 `websocket_client.h` 中用宏定义管理所有消息类型字符串。

# BUG-003 xTaskCreatePinnedToCoreWithCaps 参数顺序错误

**状态**：已修复
**发现日期**：2026-04-08
**修复提交**：`0bbfe76` + `24d10cc`
**文件**：`main/bsp/bsp_wifi.c`

## 现象
按钮监控任务创建后行为异常：堆栈深度被当作优先级，导致任务优先级极高
或堆栈极小，运行中触发 stack overflow。

## 原因
将 `xTaskCreate` 改为 `xTaskCreatePinnedToCoreWithCaps` 时，
参数顺序不同，`stack_depth` 和 `priority` 两个参数位置写反。

```c
// 错误写法（位置写反）
xTaskCreatePinnedToCoreWithCaps(fn, name, priority, arg, stack_depth, &handle, core, caps);

// 正确写法
xTaskCreatePinnedToCoreWithCaps(fn, name, stack_depth, arg, priority, &handle, core, caps);
```

## 修复
**文件**：`main/bsp/bsp_wifi.c`
按正确参数顺序重写任务创建调用。

## 教训
切换任务创建 API 时必须对照文档确认参数顺序，不能凭 xTaskCreate 的肌肉记忆。

# BUG-001 蓝牙内存释放崩溃

**状态**：已规避（代码注释掉，未彻底修复）
**发现日期**：2026-03-22
**关联提交**：`1de38fb` refactor(wifi): 注释掉蓝牙内存释放相关代码

## 现象
BLE 配网完成后尝试调用 `esp_bt_mem_release()` 回收蓝牙内存，
系统在后续操作中偶发崩溃或行为异常。

## 原因
`esp_bt_mem_release()` 必须在蓝牙协议栈完全卸载后才能调用，
时机不对或存在残留引用时会导致内存损坏。

## 修复
**文件**：`main/bsp/bsp_wifi.c`
临时方案：将蓝牙内存释放代码全部注释掉，接受内存不回收的代价。
后续应在 `esp_bluedroid_disable()` + `esp_bt_controller_disable()` 完成后再释放。

## 影响
配网完成后约 40 KB SPIRAM 无法回收，当前可接受。

# BUG-002 SPIFFS + SPIRAM 初始化内存冲突

**状态**：已规避（禁用 SPIFFS，改用 NVS）
**发现日期**：约 2026-03-31（音频模块重构阶段）
**关联提交**：`a154812` feat(audio): 重构音频模块架构并集成音频编解码功能

## 现象
同时启用 SPIFFS 文件系统和 SPIRAM 外部内存时，启动阶段内存分配器
偶发异常，表现为 heap 初始化报错或随机崩溃。

## 原因
ESP32-S3 SPIRAM 使用 `esp_himem` / `MALLOC_CAP_SPIRAM` 标记，
若 SPIFFS 分区与 SPIRAM 区域存在地址映射重叠，初始化顺序敏感。

## 修复
**方案**：所有持久化需求改用 NVS（`esp_nvs_flash`），
不再挂载 SPIFFS 分区，消除冲突根源。

## 影响
唤醒词模型文件、凭证等均通过 NVS 命名空间存储，无功能损失。

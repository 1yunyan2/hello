# BUG-007 唤醒词尾音误触发 EOS 静音检测

**状态**：已修复
**发现日期**：2026-04-09
**修复提交**：`aee301c` feat(session): 添加VAD延迟启动机制防止唤醒词尾音误触发
**文件**：`main/session/session.c`

## 现象
用户说完唤醒词（如"你好伙伴"）后，紧接的短暂停顿被 VAD 识别为静音，
EOS 定时器立即触发，发送 `stop` 指令，用户真正的问话被截断或忽略。

## 原因
服务端返回 `started`（握手成功）后，VAD 检测立刻激活，
而此时麦克风里还残留唤醒词的尾音和呼吸停顿，800ms 静音窗口被立即填满。

## 修复
**文件**：`main/session/session.c`
引入 `VAD_GRACE_MS = 500ms` 消退保护期：
- `s_vad_ready_tick`：记录服务端 `started` 响应的时刻
- VAD 检测逻辑增加前置条件：`(xTaskGetTickCount() - s_vad_ready_tick) > pdMS_TO_TICKS(VAD_GRACE_MS)`
- 消退期内即使检测到静音也不触发 EOS

## 教训
唤醒词触发到服务端就绪之间有不可控的时间差（网络+服务端处理），
VAD 激活必须加入保护窗口，避免把唤醒词本身的尾音当作句末静音。
